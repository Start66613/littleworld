# P2：Windows 正式入口与应用导航

2026-10-25，本轮继续用户授权的 OS 开发，不要求重新批准已有工作范围。

LittleWorld.exe 无参数默认进入 OS V2；--legacy 仍可启动原版桌面，--auto 保留原版回归入口。可选 LW_PIXEL_PACK 或 --os-v2 PACK 加载本地角色包；没有包时继续运行完整场景、设置与应用，并明确显示角色缺失，不下载或公开角色。固件 app_main 仍保留稳定入口，未刷机。

增加 lw_shell_host_t 导航委托，旧应用请求由 OS 的下一次 tick 处理，避免在原始点击回调中销毁发送者。进入 OS 时释放旧桌面视图，保留共享日期/宠物/存档服务；退出 OS 恢复原版桌面。Dock 实际挂载相册、音乐、回忆、三款游戏；小世界内可打开原版宠物照顾页。旧业务没有重新实现，原版宠物几何视图明确仍是旧版功能页，不作为正式像素美术。

锁屏文本改为左侧独立排版，与右侧房间分开；时钟、日期、纪念文字、解锁有真实矩形相交检查。页面与控制中心采用淡入和 ease-out 位移，关闭浮层180ms淡出，删除页面自动取消对象动画。回归实际发现音乐“下一首”超出470px父卡片，重新布局三个控制按钮后真实点击改变当前曲目。

## 实际验证

- Windows MSVC + LVGL9.5.0 编译通过。
- 系统模型22项、角色模型82项通过。
- 有本地角色包：真实LVGL指针流程128项通过；100次浮层循环、100次含全部旧应用的页面循环无对象/timer/lease增长；退出恢复旧桌面；像素换帧峰值589824B。
- 无角色包：相同128项通过，像素资源峰值0B。相册打开/切图/关闭、音乐下一首、宠物喂食、纪念页面、2048/贪吃蛇/打砖块进入与返回均实际执行。
- 16张1024×600真实帧缓冲截图在本地 reports/ui-v2/os-v2；含 Qianqian 的新图按用户指示不提交。已打开检查锁屏、宠物、音乐截图，截图不是素材合成。
- 首次测试编译引用了不存在的music_track字段，改为检查真实标题；首次真实点击暴露按钮越界，已修复。失败/修复日志均保留 reports/logs/os-p2-*。

runtime.json 是无等待虚拟时钟下的主机测量，不是持续帧率或实板堆测试。网络、声音、亮度仍是明确标记的Windows Mock；相册仍是原版示例内容。离线固件构建另记最终结果，不能据Windows通过称硬件通过。
