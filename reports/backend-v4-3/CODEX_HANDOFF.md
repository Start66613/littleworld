# Codex 交接摘要（V4.3）

完整接口文档在 `docs/handoff/CODEX_V4_3_ENGINE_API.md`（11 KB）。这一份是
**只讲结论**的版本，给不打算读长文的人。

## 一句话

技术侧本轮交付了四个可用的引擎契约（九宫格 UI 资产、场景锚点与遮挡、
统一时钟、Studio 转换），**都没有接进真实页面**，也**没有上板验证**。
要接，按下面五个问题回答我。

## 我这边已经能用的

| 能力 | 入口 | 状态 |
| --- | --- | --- |
| PNG → `.lwu`（九宫格/按钮三态/像素风） | `tools/build_ui_assets.py` | 可用，34 项测试通过 |
| `.lwu` 设备端加载与绘制 | `lw_ui_asset_add_file` / `lw_ui_asset_panel` | **代码就绪，但未链进固件**（没有页面调用，被链接器回收） |
| 角色锚点与脚底对齐 | `lw_stage_place_actor` | 可用，测试锁住"换姿势不跳"；**同样未链进固件** |
| 家具遮挡 | `lw_stage_occlude` | 可用，未接入 UI |
| 统一时钟（四态/五时段/三主题） | `lw_ui_clock_read` | **已链进固件**，已接入状态栏与锁屏 |
| Studio `.lwpack` → `.lwcx` | `tools/studio_to_device.py` | 可用，26 项测试通过 |

"未链进固件"是实测结论（`riscv32-esp-elf-nm` 查不到符号），不是保守说法：
这几组函数要等页面真的调用它们才会进镜像。

## 我需要你给的

1. **UI 组件 PNG**：命名 `icon-*` / `panel-*` / `button-*`，
   面板与按钮带同名 `.json` 写九宫格参数（`inset_left/top/right/bottom`、`pixel_art`）。
   按钮要竖排三段（普通/按下/禁用），高度能被 3 整除。
2. **家具遮挡清单**：每件"会挡住角色"的家具，给我矩形（屏幕坐标）+ 接触线 y。
   沙发扶手、狗窝内沿、桌子前沿这三个是必须的。
3. **狗窝四态竖排图**：空窝/睡觉/抬头/轻微活动，四段等高。
4. **三张场景图**：theme 0（清晨+白天）、1（夜晚+深夜）、2（黄昏），
   **必须 1024×600 RGB565**，不是五张。
5. **角色锚点**：每帧的 `anchor_x`/`anchor_y`，或者告诉我"全角色统一为 X,Y"。

## 三个不要做

- **不要**自己算时间。`lw_ui_clock_read()` 给你 `theme`，直接用它选图。
  自己判断会出现"19:30 画着正午的房间"。
- **不要**用 `lv_image_set_scale` 做九宫格。它缩放整张图，角会变形、边框会变粗。
  用 `.lwu` + `lw_ui_asset_panel`。
- **不要**在 PNG 里留半透明边缘的杂色像素。转换时 alpha 会保留，但 RGB 通道
  在 alpha=0 处不会被清理，放大时会露出彩边。

## 接口变更风险

本轮**没有**改动任何既有格式：

- `.lwp` / `.lwr` / `.lwfa` / `.lwcx` 的字节布局一个都没变；
- `lw_assets` / `lw_sprite` / `lw_visual_assets` 的 API 只增不改；
- 新增的 `.lwu` 是**独立**容器，不与既有格式共用魔数。

所以你的 V4.2 资源在本分支上仍能加载。

## 预算

单个 `.lwu` ≤ 1 MiB，最多 16 个；角色帧固定 256×256；场景固定 1024×600。
超了会明确拒绝（日志一行），不会静默降级。
