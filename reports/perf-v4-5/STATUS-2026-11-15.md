## 已经确认成立的事实

- **C6 链路真能用**：`sdio_wrapper: SDIO master: Data-Lines: 4-bit Freq(KHz)[40000 KHz]`、
  `GPIOs: CLK[18] CMD[19] D0[14] D1[15] D2[16] D3[17] Slave_Reset[54]`、
  `H_SDIO_DRV: Received INIT event`、`lw_net_wifi: station ready`。
- **扫描出真热点**：`reports/board-muse/wifi-page3.png` —— `附近网络，共 5 个`、
  `XTU-STUDENT −49 dBm 信号强·开放`、`OnePlus Ace 5 z7km −58 dBm 加密`、`OnePlus Ace 5 Pro g7av −58 dBm 加密`。
- **WiFi 与喇叭可以同时活**（队列 6 那一版）：`capabilities: brightness=2 volume=2 wifi=2 audio=2`、
  `lw_bgm: playing 1058400 B at 22050 Hz`、`bgm vol 70 → volume 70% set`。
- **「资源都没了」的真因是 FATFS 长名**：新建的 `build/os-wifi/sdkconfig` 默认
  `CONFIG_FATFS_LFN_NONE=y`，而卡上是 `littleworld-v4.json` / `*.lwp` 长名 ⇒ 卡挂上了但清单打不开，
  设备报「没卡」。补上
  `CONFIG_FATFS_LFN_HEAP=y` / `CONFIG_FATFS_MAX_LFN=255` / `CONFIG_FATFS_API_ENCODING_UTF_8=y`
  后立刻回到 `art: card: 6/6 packs [card]`。
- **卡必须比射频先起来**：`lw_net_esp_wifi_attach()` 原来在能力发布阶段（~2.1 s）就把射频拉起来，
  抢走 SDMMC 的 DMA 缓冲 ⇒ 卡挂载失败。现在 attach 只记指针，唯一通电点是
  `lw_net_esp_wifi_preinit()`，由 `firmware/main/lw_boot.c` 在 `lw_art_boot()` 之后调用。

`largest block 30720 B` 时喇叭要 8 KB 连续 DMA 块是够的，队列 6 时才 `26,959 B / 1,856 B`。

2. 若喇叭被挤掉，把 hosted 的 RX streaming 缓冲（`CONFIG_ESP_HOSTED_SDIO_..._BUF_...`）或

## 复现环境（`tools\activate_env.ps1` 现在报 `spawn EPERM`，只能用下面这套）

```powershell
$root='D:\Espressif\LittleWorld'
$env:IDF_PATH="$root\esp-idf-v5.5.5"; $env:IDF_TOOLS_PATH="$root\idf-tools"
$env:IDF_PYTHON_ENV_PATH="$root\idf-tools\python_env\idf5.5_py3.12_env"
$env:IDF_COMPONENT_CACHE_PATH="$root\cache\components"
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'
& "$root\python\python.exe" "$env:IDF_PATH\tools\idf_tools.py" export --format key-value |
  ForEach-Object { if ($_ -match '^([A-Z][A-Z0-9_]*)=(.*)$') {
      [Environment]::SetEnvironmentVariable($Matches[1],$Matches[2].Replace('%PATH%',$env:PATH),'Process') } }
$env:PATH = "$env:IDF_PYTHON_ENV_PATH\Scripts;$env:PATH;$env:IDF_PATH\tools"
$env:SDKCONFIG_DEFAULTS='sdkconfig.defaults;sdkconfig.defaults.rev3_x;sdkconfig.extra.wifi'
cd firmware; Remove-Item build\os-wifi\sdkconfig -ErrorAction SilentlyContinue
idf.py -B build/os-wifi -DSDKCONFIG=build/os-wifi/sdkconfig build
```

**删 sdkconfig 再编**是必须的：`idf.py` 对已存在的 sdkconfig 只合并不覆盖，
`SDKCONFIG_DEFAULTS` 里新加的项不会生效（这一条今晚白等了两轮编译）。
