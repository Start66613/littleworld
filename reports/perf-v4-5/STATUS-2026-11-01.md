### 本轮唯一真正落地的改动：场景卡改成有界 LRU 池

文件：`firmware/components/lw_ui/src/lw_visual_assets.c`、`include/lw_visual_assets.h`。

原实现只有 **1 个全尺寸槽 + 1 个辅助槽**，于是「桌面场景 → RPG 房间 → 宠物房间」
来回切时每张 1024×600×2 = 1.2 MB 的卡都要重新从 TF 卡读，实测 **670 ms/张**（卡 1.9 MB/s）。
现在改成 **3 槽 LRU 全尺寸池 + 3 槽缩略图池**，按名字做 key
（`scene-<theme>`、`rpg-room`、`daily-room-*`），命中就不再读卡。

真机效果（镜像 `0x241bc0` + 夜间烘焙卡）：

| 操作 | 改前 | 改后 |
|---|---|---|
| RPG → 桌面（返回） | 734 ms | **117 ms** |
| 桌面 → 世界页 | — | 77 ms |
| 世界 → RPG（首次） | 1359 ms | 1359 ms（未改善，见下） |

`lw_visual_daily_name()` 把「宠物页该用哪张房间卡」收敛到一处，预热代码和页面用的是同一个判断。

## 今晚踩过的坑（别再踩）

- **绝不要**用 `(Get-Content ...) | Set-Content -NoNewline` 回写 C 文件：会把整个文件压成一行。
  改 C 文件只用 `edit`/`write` 或落盘的 Python 脚本。
- 任何带引号的 Python 都先写成 `.py` 再跑，`python -c @"..."@` 会被 PowerShell 的引号规则剥掉。
- `tools\console_seq.ps1` 的 `cmd|delay` 里 delay 是「发完命令后等多久」，
  所以 `sched|5000` 统计的是约 300 ms 的窗口；要看长窗口必须用填充命令，并核对 `ticks × avg_gap ≈ 窗口时长`。
- 烧录后 `tap 512 578` 会落在还没消失的开机遮罩上，必须先 `status|3500` 等开机结束。
- `git stash -u` 会把 `reports/logs/` 也移走，长测期间别 stash。
