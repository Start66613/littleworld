## 2. 关键突破：像素网格终于对了

Batch 2 的失败根因是 **2× 放大网格**（行差分比 0.19 / 列差分比 9.0）。
换成"干净扁平 2D 插画 + 让服务端 pixelate 到 256"的写法后：

| 素材 | 行差分比 | 网格 |
|---|---|---|
| male_A_sunny | 0.99 | 原生 1 px ✅ |
| male_B_gentle | 1.08 | 原生 1 px ✅ |
| male_C_playful | 1.06 | 原生 1 px ✅ |
| qianqian_v2_a | 0.93 | 原生 1 px ✅ |
| qianqian_v2_b | 0.95 | 原生 1 px ✅ |
| ~~Batch2 P1~~ | 0.19 | 2× 放大 ❌ |

**结论：提示词里写 "pixel-art" 会让模型先画 128 网格再放大；写 "clean flat 2D illustration + pixelate to 256" 才能得到原生 1 px。**
