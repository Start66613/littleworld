# Little World 2.0 — 美术契约（ART_CONTRACT）

版本：v0.1（2026-10-25，DSH 代拟）
状态：**临时规范**。仓库里没有 Codex 的 ART_CONTRACT.md，本文件作为第一版契约；
Codex 若产出正式版，以正式版为准，本文件保留差异记录。

| 项目 | 值 |
|---|---|

| 分辨率 | 1024 × 600（横屏，16:9.375） |
| 渲染 | LVGL 9.5，RGB565 |
| 顶部栏 | 64 px |

| 底部 Dock | 96 px |

出图按 **16:9** 画（1024×576），上下各留 12 px 余量由 Codex 裁切或拉伸背景层；重要元素不要贴边。

## 2. 配色（与现有 UI 主题一致，cream 主题）

| 背景下 | `#F4E9FB` |

| 卡片柔光 | `#FFF5F8` |
| 正文 | `#4A3B45` |

| 主粉（accent） | `#F58FAE` |

美术可以比 UI 色更柔和，但**主色相必须落在这几个色附近**，否则集成后会打架。
允许的辅助色：奶油黄 `#FFF0C9`、淡米 `#F6E7D8`、雾蓝 `#DDEFF7`、鼠尾草绿 `#CFE8D8`——都只用低饱和。

## 3. 风格

- 手绘绘本质感：柔和水彩/彩铅边缘，轻微纸纹，**不要**硬描边、不要赛璐璐高对比。
- 光：左上暖光，柔和阴影，不要强烈投影。
- 线条：若有轮廓线，用比填色深 10–15% 的同类色，不用纯黑。
- 禁止：像素风（本阶段）、3D 渲染感、霓虹/赛博、写实照片、文字水印、签名。

## 4. 角色规范（宠物）

- 一只，**完整身体**，四足或软体皆可，轮廓清晰，可做表情与动作。
- 比例：圆润，头身比约 1:1.2，四肢短；耳朵/尾巴/触角等特征要能一眼识别。
- 视角：**正面 3/4 微侧**（便于做待机与看向观众），另需一张严格正面用于表情。
- 画布：1:1，2048×2048（2K）；角色占画布高度 70–80%，四周留透明边。
- 锚点（供 LVGL 集成）：角色**双脚中心**为原点；导出时在清单里给出脚底距画布底边的像素距离。
- 透明：必须真透明（Image2.5 原生抠图），不允许"白底假装透明"。
- 交付：单张 PNG（透明）+ 精灵图（后续）。

## 5. 场景规范（小房间）

- 1024×600 构图，横屏，视线高度约 1.1 m，一点透视或轻微两点透视。
- 必须包含：窗户（带窗外天光）、小床、地毯、小台灯、小书架、植物、小相框。
- 中景留出 **约 420×360 的空地**放宠物（建议画面中心偏左），不要用地毯花纹或家具腿破坏这块。
- 分层交付（后续）：`bg`（墙/窗/固定家具）、`mid`（地毯、矮家具）、`fg`（前景虚化植物/光斑）。
- 第一版先出**整图**（1024×600 无损 PNG），分层由 Codex 决定是否需要。

## 6. 首页氛围参考

- 16:9，2048×1152。用于确定：主角位置、家具位置、光源方向、信息区留白。
- 图上**不要**生成任何文字/按钮/图标标签——这些由 LVGL 实时绘制。
- 信息区（右侧卡片、顶部栏、底部 Dock）用纯色块示意即可，不要画细节。

## 7. 动画规范（第二阶段）

- 帧尺寸：512×512（透明），角色占高 70%。
- 帧率：8 fps；短循环 6/8 帧，待机 8–12 帧。
- 精灵图：**横向单行**，从左到右为时间顺序；帧数写进清单。
- 锚点：每帧脚底中心对齐同一像素坐标（漂移 ≤ 2 px，需逐帧检查）。
- 动作优先级：待机呼吸 → 眨眼 → 开心 → 被抚摸 → 吃东西 → 玩耍 → 睡觉 → 好奇。

## 8. 命名

```
<类别>_<对象>_<状态>_<版本>_<尺寸>.<ext>
例：char_mochi_idle_v01_2048.png
    room_bedroom_full_v01_2048x1152.png
    anim_mochi_blink_v01_512_sheet.png
```
- 类别：`char` / `room` / `home` / `icon` / `anim` / `map`
- 状态：`front` / `idle` / `happy` / `sleep` / `full` / `blink` ...
- 版本：`v01`、`v02`，不覆盖旧文件。

## 9. 格式与体积

| 类型 | 格式 | 说明 |
|---|---|---|
| 角色 | PNG-24 带 alpha | 单帧 ≤ 1.5 MB |
| 场景 | PNG-24 | 整图 ≤ 3 MB |
| 精灵图 | PNG-24 带 alpha | ≤ 8 MB，LVGL 侧再转 C 数组或 RGB565A8 |
| 预览 | JPG/PNG | 长边 1024，仅用于评审 |

LVGL 侧约束：单张纹理建议 ≤ 2048×2048（PSRAM 32 MB 可放宽，但为帧率优先）；
最终按需缩到 1024 宽（背景）或 512（角色）。

## 10. 验收门槛（不达标不进素材包）

1. 四肢/眼睛/耳朵结构合理，无多手多脚、无融合。
2. 真透明，边缘无白边/灰边。
3. 无文字、无水印、无签名、无 UI 装饰。
4. 主体完整，未被裁切。
5. 多张同类素材的配色与比例一致（同一角色的多次生成必须可互换）。
6. 场景透视合理，宠物活动区无遮挡。
