## 2. 画布与锚点（强制）

| 项目 | 值 |
|---|---|
| 单帧画布 | 256 × 256，RGBA，透明背景 |
| 角色高度 | 194–198 px（idle 站立） |
| 脚底锚点 | y = **225** |
| 水平锚点 | x = **126**（身体包围盒中心） |
| 顶部留白 | ≈ 28 px |
| 允许帧间漂移 | ≤ 2 px |

两人共用同一锚点，所以摆放时只需对齐脚底 y 与 x 中心。
LVGL 侧坐标：`sprite_x = anchor_x - 126 * scale`，`sprite_y = anchor_y - 225 * scale`，`scale` 取整数（1 或 2），最近邻。

## 3. 像素与配色

- **1 像素 = 1 像素**，禁止在生成阶段做 2×/4× 块状化；如需放大，只在渲染时用最近邻整数倍。
- 无抗锯齿：alpha 只有 0 或 255；边缘不得出现灰半透明。
- 描边：暖深灰 `#393834`（暗部 `#23221F`），禁止纯黑 `#000000`。
- 主色板（沿用 qianqian）：

| 用途 | 色值 |
|---|---|
| 描边/深发 | `#393834` |
| 深阴影 | `#23221F` |
| 白（衣服/高光） | `#FCF5F1` |
| 皮肤 | `#FCE3D2` |
| 皮肤阴影 | `#EEAE98` |
| 粉色点缀 | `#F4B2B0` |
| 腮红 | `#E39392` |
| 次级灰 | `#504F4C` |

- 男方服装：白色宽松 T 恤（`#FCF5F1` + `#E8DFDB` 阴影），深灰蓝短裤；不使用 qianqian 的粉色蝴蝶结。
- 颜色预算：30–45 色覆盖 90% 像素。

## 4. 男方外形（必须保留的个人特征）

1. 黑色、蓬松、偏厚的中长刘海，自然垂落、略带凌乱，**遮住额头与部分眉毛**。
2. 深色眼睛（深棕 `#2A1612`），眼型平缓，眼神平静、微困。
3. 表情基调：平静、慵懒，不笑或极浅的嘴角。
4. 白色宽松 T 恤，圆领，袖口略宽。
5. 体型：Q 版 2.4 头身，**稍圆润、肉乎乎**，肩略窄，手臂短，不夸张、不丑化。
6. 识别点优先级：发型轮廓 > 眼神 > 白 T > 体型。

## 8. 双人互动（位置与朝向）

| 互动 | 站位 | 朝向 | 同步 |
|---|---|---|---|
| 彼此靠近 | 间距 120→60 px | 互相对视 | 8 帧同速 |
| 并排坐下 | 间距 70 px，脚底同高 | 同向朝前 | 两人坐下帧对齐 |
| 互相挥手 | 间距 90 px | 相对 | 同一帧序 |
| 一起看窗外 | 间距 60 px，背对观众 | 同向 | 循环呼吸 |
| 递小信封 | 间距 50 px | 相对 | A 伸手 → B 接过（2 段） |
| 同步开心 | 间距 70 px | 同向 | 同帧触发 |
| 一起休息 | 间距 70 px | 同向 | 睡姿循环 |
| 一起玩游戏 | 间距 80 px | 同向 | 手部微动循环 |

- 碰撞范围：每人 60×40 px（脚底矩形），互动时最小间距 50 px。
- 朝向用水平翻转实现（`lv_image_set_scale_x(-1)` 或预生成镜像帧），但**男生左手/右手道具** 需检查翻转后是否合理。

## 9. 渲染（LVGL / ESP32-P4）

- 最近邻整数倍缩放：1×（256 原生）或 2×（512，屏幕上一人约 400 px 高）。
- 关闭所有插值：LVGL 9 用 `lv_image_set_antialias`（若启用）必须为 0；`lv_image` 的缩放本身是最近邻。
- 动画用 LVGL `lv_anim` 或定时器切换 `lv_image_set_src`，帧率 8–10 fps。
- 每帧 256² RGBA = 256 KB 内存；若走 RGB565A8 可降到 192 KB。建议 idle/walk 只加载当前方向。
