# Little World Studio

一个只在本机运行的纪念日内容编辑器：把纪念日、小信封、回忆时间线、相册和「我们的故事」整理成
一份带版本号的内容包（`.lwpack`），供未来的 Little World 固件读取。

> **边界说明（重要）**：当前固件**没有**这个内容包的读取器。Studio 生成的包不能直接烧写，
> 也不能声称设备已经支持。`内容与导出` 页的「与 Little World 的连接」逐条列出了哪些字段
> 已经能映射到现有 C 结构（纪念日期、公开回忆、RPG 台词与选项），哪些还需要适配
> （信件解锁、图片加载、房间热点、任务配置）。

## 运行要求

- Windows（启动脚本与截图均在该平台验证）
- Node.js **22.18 或更高**（推荐 24 LTS）
- 首次运行会联网安装依赖；此后完全离线

## 启动

双击 `Start-Studio.bat`。脚本会检查 Node 版本、首次运行时执行 `npm ci`、构建前端，
然后启动本机服务并打开浏览器（`http://127.0.0.1:4317`）。

命令行方式：

```bat
npm ci
npm run build
npm start          :: 只跑服务，需先 build，监听 4317
npm run dev        :: 开发模式，Vite 热更新在 4318，/api 代理到 4317
```

窗口保持打开即可编辑；关闭窗口即停止。端口被占用时会明确报错并退出，不会静默换端口。

## 六个模块

| 模块 | 内容 |
| --- | --- |
| 纪念日 | 标题、日期、说明；预览区显示「距今天数」和下一次纪念日 |
| 小信封 | 三类信件（今天 / 心愿 / 信），可设解锁日期，预览中模拟解锁 |
| 回忆时间线 | 日期、标题、正文、标签、关联照片、是否公开（公开条数受固件上限约束） |
| 相册 | 本地图片、说明、封面、拖动排序、删除 |
| 我们的故事 | 最多 8 个章节，每章最多 8 句对话、2 个选项，`nextId` 指向下一章或结束 |
| 内容与导出 | 统计、导出 `.lwpack`、下载项目文件、导入、备份与恢复、兼容性检查 |

右侧「即时设备预览」按 1024×600 的 7 英寸屏模拟显示，可切换主题与预览日期。

## 保存与文件

- 编辑后 **900 ms 自动保存**，`Ctrl + S` 立即保存，状态栏显示 `有修改 / 保存中 / 已保存`。
- 保存采用「临时文件 → fsync → 重命名」的原子替换，每次覆盖前先把旧版本写入
  `backups/`，只保留最近 20 份。
- 保存时携带版本戳；若项目已被另一个窗口更新，会拒绝覆盖并提示改用「另存为」。
- 项目默认存放在 `studio/private/projects/<uuid>/`，可用环境变量 `LW_STUDIO_DATA`
  指向其它目录。`private/` 已在 `.gitignore` 中，个人内容不会被提交。

### 导入 / 导出

- **导出内容包** → `LittleWorld-<项目名>.lwpack`（ZIP，未压缩存储，含 SHA-256 清单）。
- **下载项目文件** → `.lwstudio`，与 `.lwpack` 是**同一个容器格式**，两者都能重新导入。
- **导入** 始终创建副本，不会覆盖已有项目；导入时重新校验 ZIP 结构、路径、CRC、
  SHA-256 与图片真实格式。
- **备份与恢复** 可把任意历史版本恢复成一个新项目。

## CLI 校验

```bat
npm run validate -- examples/demo.lwpack
npm run validate -- examples/demo.lwpack --emit-c studio-content.h
```

第一条只校验并打印统计；第二条额外生成一个**纯文本 C 适配头文件**（`lw_memory_t[]`、
`lw_rpg_dialogue_t[]`），供开发者审查。它不会修改固件，也不会写入任何固件目录。
目标文件已存在时拒绝覆盖。

## 测试

```bat
npm test          :: 51 项单元 / 集成测试（日期、模型、内容包、存储、HTTP）
npm run test:ui   :: 8 项 Playwright 端到端测试，需本机安装 Edge
```

`npm run test:ui` 会自起服务并把数据写到 `private/e2e-projects`，不会碰真实项目。
`reports/screenshots/` 里的 8 张图由该套测试生成。

## 安全边界

- 服务只监听 `127.0.0.1`，校验 `Host` / `Origin` / `Sec-Fetch-Site`，拒绝跨站请求。
- 除 `/api/session` 外所有接口都要带每次启动随机生成的 `X-Studio-Token`。
- 响应带 CSP（`default-src 'self'`），不加载任何外部资源。
- 图片只接受 PNG / JPEG / WebP 位图，按文件头判断真实格式；不接受 SVG。
- 解包前先读 ZIP 中央目录做预检，拒绝路径穿越、重复文件名、ZIP64、分卷与超限声明。


## 已知限制

- 固件侧读取器尚未实现，内容包只能被 Studio 自己重新导入。
- 动画开关、键盘快捷键之外的交互细节仍在迭代。
- 预览中的日期为模拟值，与设备时钟无关。
