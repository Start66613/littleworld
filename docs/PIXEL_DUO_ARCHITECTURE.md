# 双角色运行框架 · P1

2026-10-25。继续使用 lw_core 的日期、旧宠物存档和 arcade_core；双角色会话模型新增为独立 lw_duo 组件，不改变 LW_SAVE_VERSION 或旧记录布局。持久化双人进度需后续单独的版本/迁移设计，P1 不宣称已有双角色独立永久存档。

- lw_duo：纯 C、确定性 seed。两个独立 actor 的位置、目标、8 向朝向、睡眠、动作和行为截止时间；有限步长移动、碰撞距离约束和场景边界。无 LVGL、网络、LLM。
- 互动协调：request → approach → align → act → finish。站位保留左右次序，避免交叉；仅两人都到位且清醒才开始同一交互时钟。超时取消，触摸/休息可中断。睡眠不会被自主计划叫醒。
- 互动目录：靠近挥手、并排、坐下、递信、看窗、庆祝、共同休息。P1 实现语义/站位/同步和退场；缺少对应美术时明确 idle/方向姿态回退，不能说已经完成挥手或递信动画。
- lw_sprite/lw_assets：复用已测资源 lease/播放器，新增原生像素设置、当前位置、外部时钟驱动。两位 actor 的 clip 可以不同；双人动作共享协调器 elapsed，普通动作独立相位。
- lw_duo_view：LVGL 场景角色层，按脚底 y 排序遮挡；人物透明区域不遮住导航，触摸映射到 actor id，弹出各自操作。父页面删除统一释放实例、timer 和所有活动 lease。
- host/pixel_pack：标准 C 按需读取 LWPX 文件单帧，metadata 与源 .tres 分离；不是在 ESP32 上运行 Godot。导出脚本验证固定源、原始 Atlas Rect2、逐帧时长、无损补边及最近邻规则。

1024×600 技术房间保留简洁顶栏和 Dock，人物用原生 1×，场景面积优先。测试男方只作可识别占位并持续显示 TEST/非最终素材；不加载或公开真人照片，不冒充定稿。资源与包含角色的截图都在忽略的 private/pixel-duo。

P1 的本机性能报告测实际加载字节、读取次数、timer/对象数、循环退出回落、CPU 时间和真实壁钟时间。以可复现测试为证据，不把无等待的跑满速吞吐称作真实设备帧率。固件离线编译会限制并行度，防止上次主机 cc1plus 内存耗尽；无设备连接或写入动作。
