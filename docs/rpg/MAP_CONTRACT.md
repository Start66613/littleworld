# MAP CONTRACT — 房间、网格与碰撞

版本 v0.1 · 2026-10-25 · DSH · 对应实现 `rpg/data/lw_rpg_home.c` + `rpg/include/lw_rpg.h`

## 1. 网格

| 项 | 值 |
|---|---|
| 房间尺寸 | **16 × 8 格** |
| 单格 | 44 px（1024×600 下 704×352） |
| 原点 | 屏幕 (32, 104) |
| 坐标 | `(0,0)` 左上，x 向右，y 向下 |
| 存储 | `floor[128]`，1 = 可走，0 = 阻挡 |

- 家具块只做阻挡，不参与寻路权重（后续可加"绕行代价"）。

## 3. 寻路

- 4 方向 BFS，队列与 visited 定长 128，无动态分配。
- 返回**方向序列**（0=下 1=左 2=右 3=上），逐格移动，140 ms/格。
- 目标不可达或目标格阻挡 → `lw_rpg_tap_tile` 返回 false，角色原地不动。

## 4. 跟随

- qianqian 每帧检查：与玩家曼哈顿距离 > 2 → BFS 到玩家当前格。
- 玩家移动中不重算，避免抖动；距离 ≤2 时停止。
- 两人允许短暂重叠；下一帧按新距离让位。

## 5. 视觉分层（给渲染层）

| 层 | 内容 | 说明 |
|---|---|---|
| 0 地板 | 木地板/地毯 | 烘焙进背景，不带碰撞信息 |
| 1 家具 | 桌子/盆栽/床 | 可遮挡角色下半身（y 排序） |
| 2 角色 | 两人 | 按脚底 y 排序绘制 |
| 3 热点标记 | 小圆点 + 标签 | 可交互时呼吸放大 |
| 4 UI | 任务本、对话框、按钮 | 固定屏幕坐标，不随地图滚动 |

本版房间小于屏幕，不需要摄像机滚动。若将来加房间滚动，以 44 px 整数倍对齐，禁止半格偏移。

## 6. 素材规格（给美术）

| 素材 | 尺寸 | 说明 |
|---|---|---|
| 房间背景 | 1024×600 | 无角色、无 UI、无文字；地板留空区域 y 320–470 |
| 家具前景 | 单件 64–128 px | 透明 PNG，按脚底对齐放置 |
| RPG 角色 | 48×64 或 64×80 | 脚底中心锚点；先做 48 与 64 两版对比可读性 |
| 热点标记 | 24×24 | 三态：默认 / 可交互 / 已收集 |

**禁止**把 256 px OS 立绘直接缩成 48 px 当 RPG 精灵。
