# GAME DESIGN —《我们的故事》RPG 竖切片

版本 v0.1 · 2026-10-25 · DSH

## 1. 目标与边界

7 寸 1024×600 触摸屏上、**一间小屋、两个角色、一个任务**的可玩竖切片。
不依赖 Codex 的 OS 即可独立运行与测试；OS 只负责"从首页进入/退出"。

明确不在本版：多房间、战斗、数值养成、经济、联机、Godot 引擎移植。

## 2. 核心循环（一局 3–5 分钟）

```
进入小屋 → 触摸地面移动 → 走到 3 个热点 → 每个热点触发对话 → 收集 3 件物品
        → 任务完成 → 解锁 1 个摆件（奖励事件回传 OS）→ 可退出
```

## 3. 角色

| 角色 | 控制 | 行为 |
|---|---|---|
| 男方（玩家） | 触摸目标格，BFS 寻路走过去 | 走路动画 8 帧 / 100 ms |
| qianqian | 自动 | 与玩家距离 > 2 格时按 BFS 跟随，否则原地待机 |

两人共用一张网格与一套碰撞；qianqian 不会挡路（软跟随，允许重叠一格，下一帧再让开）。

## 4. 三个热点

| 热点 | 位置（tile） | 交互结果 |
|---|---|---|
| 照片盒 | (5,3) | 对话 2 行 → 收集「照片」 |
| 信封桌 | (9,4) | 对话 2 行 → 收集「信封」 |
| 小盆栽 | (3,3) | 对话 1 行 → 收集「小盆栽」 |

- 交互半径 1 格（曼哈顿距离），可交互时热点标记放大 + 提示条淡入。
- 已收集的热点再次点击无反应（不重复触发）。

## 5. 任务

《整理回忆盒》：收集 3 件 → 进度 3/3 → 完成 → 解锁 `reward_id=9001`「小相框」。
任务本（右栏）显示标题、三项勾选、剩余数量；完成后显示解锁物。

## 6. 对话

- 数据驱动：`lw_rpg_dialogue_t`（说话人 + 文本 + 可选分支）。
- 交互：点任意处推进一行；最后一行后若有分支，显示 2 个按钮（≥44 px 高）。
- 本版所有文案均为**明显的示例文本**，不含真实日期/回忆。

## 7. 反馈与手感

| 反馈 | 实现 |
|---|---|
| 点击地面 | 目标格出现 0.4 s 的落点圈，角色立即起步 |
| 走到热点 | 热点标记呼吸放大，出现"点一下"提示 |
| 对话推进 | 文本逐行出现，可跳过 |
| 收集完成 | 任务本对应项打勾 + 轻微弹跳 |
| 任务完成 | 奖励卡片从底部滑入，2 s 后收起 |
| 退出 | 左上角返回按钮（mock 阶段回桌面占位） |

音效：默认关闭，开关在设置；无音频设备时静默降级（不报错）。

## 8. 画面构成（1024×600）

```
┌ 头部 64 px：标题 + 返回 ────────────────────────┐
│ 房间 16×8 格 @44 px = 704×352（左上 32,104）  │ 任务本 176×300
│                                                │ （右上 828,96）
├ 底部 132 px：对话框（仅在对话时出现）──────────┤
```

## 9. 技术形态

- 纯 C 核心 `rpg/`（无 LVGL / 无 IDF），Windows 上单元测试 85 项。
- 渲染与输入由宿主提供：mock 用 Python 出图，正式由 Codex 用 LVGL 9.5 接。
- 数据（房间/热点/任务/对话）编译进固件以省 Flash 与解析开销，同时保留 JSON 导出脚本。
