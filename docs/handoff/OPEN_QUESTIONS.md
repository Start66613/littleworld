## D. 我知道但还没解决的问题

1. **`custom-size-pixel-gen-run` 无法直接输出 512**（报 `dimensions_too_large`），所以"512 生成 → 2× 降采样"这条路走不通，只能用"扁平插画 + 服务端 pixelate 256"。
2. **高度不可控**：提示词写 198 只能说"接近"，实际在 188–227 之间浮动；要精确只能多轮生成挑一张，或接受 ±10。
3. **qianqian 重制版比原版高**，如果最终要和原版动画帧混用，必须先统一高度。
4. **测试 A 占位**仍在 Codex 的 OS 截图里，等男方定稿才能替换。
5. **没有板测**：所有结论基于 Windows mock，屏幕/触摸/内存未在 P4 上验证。
