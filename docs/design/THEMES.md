# 主题与壁纸

Sakura 是日光、奶油墙、粉色窗帘与沙发；Moonlight 是深蓝紫房间、月亮星光和暖色织物；Pixel Home 是鼠尾草绿沙发、格纹帘和木色地面。所有系统表面、正文/辅助文字、强调色和状态栏同步使用主题 Token。

实现分别保存 theme 和 wallpaper 两个索引；P1 选择主题时同时选配对应内置房间。预览索引不改系统偏好；确认才保存，取消恢复原值。后续可以独立选择壁纸，但还没有自定义图片导入或 SD 浏览，不显示虚假的“导入成功”。

内置房间由 lw_os_wallpaper 在实际大小绘制；缩略图复用同一绘图逻辑。它不把人物烘焙到背景，也不包含交互文字、Dock 或滑块。未来 DSH 背景以1024×600为逻辑坐标，人物站位区/遮挡层由单独JSON定义。

设置记录是独立24字节 LWO2 v1 + CRC32，包含亮度、音量、静音、勿扰、小组件、主题/壁纸。Windows 采用同目录临时写入与原子替换；失败保留dirty供重试。记录无SSID/密码，旧72字节存档格式不变。ESP端的NVS偏好存储尚待P3/P4适配，不假装重启恢复已在板上验证。

所有带 qianqian 的截图留在忽略的 reports/ui-v2/os-v2。主题规范和绘图代码可本地提交；未经用户另行授权不推送角色图片或私人照片。
