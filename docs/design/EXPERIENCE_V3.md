# P5 体验与动效规范

基线31dba23，分支agent/os-v2-experience-v3。复用已完成的OS/RPG/缓存；本轮不开发ESP32后端，不修改DSH冻结核心，不调用收费生成。含Qianqian的新图仅本地。

桌面左侧只保留标题、可打开的纪念卡片与信封，右侧为实时绘图房间。角色独立于背景；壁纸→阴影→角色→前景小桌/植物→系统Dock/浮层。场景仍由LVGL绘制，家具不烘焙操作文字。角色原生1×；未验收男方继续TEST A，DSH B只是候选。

动效不保留两份场景树或全屏快照：交互导航先70ms离场，再220ms横向入场；控制中心从右侧轻弹290ms；对话下方20px弹入240ms；提示自上方10px滑入170ms；奖励28px回弹420ms。主题260ms内在同一绘图对象上叠绘旧/新房间，过渡后跳过旧绘图，额外上下文仅8字节，不分配两张高清壁纸；过渡期间绘图命令增加，低性能设备用减少/关闭档跳过。按钮按下2px、释放140ms轻弹。只有有限任务反馈，没有常驻环境动画timer。所有动画绑定LVGL对象，删除对象自动取消。

完整/减少/关闭三档。减少保留90ms低幅透明变化，无空间位移；关闭即时更新。关闭使用既有animations设置保存，减少档仅本次会话，持久化留给DSH契约。切档清理旧退出浮层、取消关联动画并重建当前页面。锁屏重复显示复用当前实例；时钟更新文字，无每秒重建。短上扫取消，超过72px松手解锁，按钮始终可点。

这些档位控制系统装饰动效与旧宠物UI的呼吸/晃动，不自动暂停游戏算法或媒体内容，也不把原版像素角色替换成未验收的静态候选。停止OS后旧首页的既有呼吸动画会恢复；回归比较进入前后的原版基线，不能把它当作OS泄漏。

系统与旧应用共享临时palette，旧版已保存主题编号保持不变，停止OS时撤销临时palette。三主题同步文本/控件/应用，照片自身色彩保持原样。系统字体18/22/28，数字44/88；日期调整按钮提升为44×44，主要动作48–60高。

相册默认为空，明确选择后才能看示例。照片源由UI接口注入，不依赖TF驱动；缩略列表不展开照片，全屏仅持有一张，等比缩放。释放顺序为删除图片对象、丢弃LVGL缓存、调用源release。错误保留切换/重试/关闭。音乐只模拟进度，界面持续注明无真实音频，不伪装已输出声音。

纪念日计算与日期存档沿用旧逻辑；时间线示例明确标注，可注入借用的故事记录，不把默认样例当私人经历。RPG地板以绘图替代128个格对象；固定家具与原地图阻挡一致。点击标记/行走插值只属于表现层，任务、路径、奖励和存档均调用冻结核心。测试标记不是最终美术。

检测采用真实指针、LVGL帧缓冲、对象/timer/lease/动画计数与源加载/释放。截图不是AI生成图，虚拟时钟吞吐不代表ESP触摸延迟或持续帧率。
