# 系统动画

P5最新实现以EXPERIENCE_V3.md为准：页面离场/横向进入、右侧控制中心、弹性对话、奖励回弹、主题绘图混合和三档动态已实际实现。以下为P0/P1历史，不代表当前能力。

页面打开：内容 translateY 10→0，240ms ease-out。控制中心：面板 translateY -30→0，280ms。信封/编辑弹层：18→0，240ms；Toast：14→0，200ms。关闭浮层和解锁使用 180ms opacity 淡出，完成后删除对象。对象删除时 LVGL 取消绑定动画。

触控反馈使用统一按下透明度变化；Dock 与列表不采用夸张弹跳。主题确认/取消重绘统一 palette；本轮采用页面进入过渡，未同时保留两套全屏背景做交叉淡化，避免峰值资源翻倍。最终壁纸过渡与背景环境动画将在视觉验收后补充，不声称现已全部完成。

角色复用 lw_sprite 外部时钟：单角色普通动作独立计时，互动 ACT 用 coordinator 的同一 interaction_ms。idle125ms，walk100ms，sleep_idle 累计舍入267/266ms；不以系统 20ms timer 充当角色帧率。真实人物帧原生1×、最近邻、无平滑位图缩放。

本轮环境场景为静态 LVGL 绘图，角色与系统浮层有实际动画。没有付费生成“过渡视频”，也不把概念图当动画截图。Windows 自动测试采用无等待虚拟时钟，性能报告不将其吞吐解释为 50FPS/60FPS 实机性能。
