# Little World OS 系统设计

2026-10-25。依据用户提供的 Little World OS.docx 执行 P0/P1；此文档是工程实现说明，不把附件中的示例、建议路径或 DSH 自评当作已完成事实。

本轮建立可运行的 1024×600 系统视觉候选：左侧轻量纪念信息，右侧日常房间，底部悬浮 Dock，顶部系统状态。像素人物保持原生精细度，系统文字、图标和触控组件使用现代排版。不是把整张生成的界面图片贴到屏幕上。

Sakura 以暖米色房间和低饱和粉色织物为主；Moonlight 改为夜窗、月亮星点和深蓝紫系统；Pixel Home 改为草绿色织物、格纹与木色日常。三套主题同步改变桌面、设置、Dock、控制中心、锁屏和文字对比。内置场景由原创 LVGL 绘图组件实时绘制，不依赖收费生成和高清背景解码。

本轮房间、图标与场景构图均为可修改的设计候选。qianqian 来自原仓库，TEST A 只验证技术；男方候选尚未美术验收，不能拿测试人偶证明两人画风统一。正式房间和人物组合须用户视觉确认。

入口 tools/run_os_v2.ps1；加 -Test 自动构建、运行真实指针流程、截图与资源循环检查。默认稳定固件/原 UI 入口保留。相册、音乐、回忆、游戏可由 Dock 挂载原版组件，视觉升级与复杂内部导航待 P5，不冒充已全面改造。

分层：lw_os（LVGL Shell/Overlay）→ lw_system（共享状态、异步网络、独立设置）→ backend（Windows Mock 或可选 BSP 适配）。Windows 状态栏与网络详情明确模拟。BSP 亮度/音量接口已提供，但无线、NVS 设置、实体待机/唤醒尚待后续真实适配，编译不等于板测。

下一阶段的入口条件：用户确认这一轮系统视觉方向后，再扩展正式 Shell 迁移、应用内部导航、硬件服务和素材部署。付费美术另需批次预算；不得借 UI 验收默认取得付费或刷机授权。
