# 导航与生命周期

P5更新：Windows默认OS入口和lw_shell_host_t桥接已在P2完成；应用内部导航已委托给当前OS。新增纪念卡片、设置二级返回、相册全屏关闭、游戏暂停/返回桌面和锁屏上扫。具体行为与当前Host验收见EXPERIENCE_V3.md；以下保留早期设计历史。

独立 --os-v2 入口启动 lw_os；--os-v2-test 使用隔离存档和确定性时钟。主线稳定入口、旧 shell 和旧 App 继续保留。新 Shell 的 page 为桌面、双人世界、设置、主题，以及四个旧 App 挂载入口；返回桌面按钮固定在右上。

Dock 固定小世界/相册/回忆/音乐/游戏/设置。主页面切换先调用旧 App destroy，销毁页面对象与角色 lease，再构建页面；模型保持会话状态。调用 lw_os_stop 释放 OS timer/对象，恢复上一 screen。旧 App 内部部分返回事件仍依赖旧 Shell，迁移桥接需 P2/P5 专门处理，不能据 Dock 打开成功宣称内部全链路已移植。

Overlay 的宿主独立于当前 App：控制中心 → 网络列表 → 密码键盘 → 连接结果 → 网络列表 → 控制中心；不会为打开控制中心清空 App。点击关闭回到原页。应用 timer 和角色模型在浮层下继续运行；锁屏时暂停人物推进，不触发 MCU 睡眠。

状态栏右侧点击是控制中心稳定入口；右侧下滑有手势入口。桌面长按进入编辑浮层，可选择主题、小组件或进入房间。手势入口需设备触摸实测后再调整边缘阈值，不以鼠标验证代替 GT911 实测。

UI 事件仅排队 action，20ms 主 timer 执行导航，避免在输入对象的事件栈中直接销毁整个页面。控制中心/设置共享一个 lw_system 实例；主题预览使用临时索引，确认才写入偏好，取消或离开回到保存的主题。

系统弹层最大一份活动内容；退出浮层可用 180ms 淡出，旧对象完成后删除，父页面销毁会同时取消其动画。没有为每个应用各建一套系统弹层。
