# 系统组件

P5当前规范见EXPERIENCE_V3.md及docs/handoff/DSH_UI_CAPABILITIES_V3.md：控制中心去掉重复主题入口，增加能力禁用态；相册/故事可注入只读源，旧应用使用临时统一palette；动效支持减少/关闭。以下为P0/P1历史记录。

lw_os_design 提供 surface、label、统一线性 icon、房间 wallpaper 和位移动画。图标由 LVGL 绘图指令实现，遵守统一 48 单位坐标、2/3px 线宽，不使用 Apple 品牌资源。图标/文字与按钮分离，按钮拥有真实点击回调和按下反馈。

状态栏显示日期/时间、网络图标状态和静音标记；Windows 模拟长期可见。Dock 使用统一 44px 图标底座、中文标签和当前应用指示。房间单独绘制，人物独立精灵层，脚底阴影及 y 深度排序；动态命中区跟随人物和躺姿变化。

控制中心是独立 Overlay：网络大块、勿扰/锁屏、两个垂直滑块、音乐预览、静音/主题和设置入口。滑块改变共享状态；释放时保存，安全亮度最低 10%。设置页面使用 7 类侧栏，开发者信息藏在关于设备内，避免占据普通用户首页。

网络列表显示模拟 SSID、dBm、加密状态；原生密码 textarea 使用掩码、长度限制和真实屏幕键盘。连接中、密码长度错误、模拟认证失败、成功、关闭、断开和忘记均有独立状态。模拟密码既不进入偏好记录，也不输出日志；wrongpass 是固定测试失败输入，不是真实网络凭据。

主题页为三个场景缩略图及统一调色的即时预览，附明确确认/取消。锁屏显示大时间、日期、纪念天数和无密码解锁。熄屏仅 Windows 黑色浮层演示，不能解释成背光或 MCU 待机实测。

Toast 有统一表面/字级、自动消失及勿扰抑制；今日信封是可交互浮层。通知历史、系统级全局通知队列、可导入壁纸、布局编辑器和全硬件电源策略留待 P2–P4。P1 的功能存在与最终产品完成度分开验收。
