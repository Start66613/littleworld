# Little World 2.0 首页与宠物页设计

2026-10-25；Codex 设计负责人。方向草案待用户确认，接口契约 v1.0.0。首轮只做首页和宠物页，现有其他应用与业务保留。

## 生活场景先于组件
打开设备先看见一间被柔暖窗光照亮的小房间：窗帘、床、低书架、地毯、食碗和玩具都有生活位置。角色在地毯上呼吸、看向人。右侧是一张墙上的小纪念纸与桌边今天的信封，底部为细长的收藏架式 Dock。信息从场景长出来，不把现有卡片改色作为升级。

首页约三分之二留给房间和居民；纪念天数是短文字，信封点开再读正文。床、食碗、玩具和居民直接可点；Dock 保留原导航语义。顶栏继续显示真实/DEMO 时间状态，不能画进背景。不要把角色缩成头像，重要家具不占角色脚下留白。

宠物页进入同一房间更亲近的构图；原生 256 px 全身角色，手势热区在角色周围。饱腹/精力/亲密用一行轻量文字，详细数值需要时再展开。食碗=喂食、玩具=玩耍、床=休息、摸角色=抚摸；短反馈靠近角色，几秒后淡出。不用整页进度条和操作面板抢走视觉中心。

## 实现边界与层级
保持 1024×600，先兼容原顶栏 64 / 内容 440 / Dock 96 的页面框架；完整背景按 screen y=64 对齐裁切进入内容区。各层与家具命中框写在 ART_CONTRACT；素材无法匹配时返工或协商，不拉伸。

资源注册、取帧、动画、背景及热区做成小型 C 组件；场景用 home/pet 两份布局配置，输出语义 action，不重新实现 lw_core。正式包经过方向确认、技术检查和人工验收后再为原 lw_app_home/lw_app_pet 安装资源视图；原版默认仍可运行，技术测试入口独立。

## 动效
页面沿用 180 ms 渐入、220 ms 轻上移，后续确认实际素材后可减小位移；动画偏好开关始终有效。触摸家具给局部响应与角色动作，不做全屏晃动。一次动作结束回 idle；睡眠低帧率；离页清 timer 和资源。动画是生活细节，不持续遮挡文字。

## 第一阶段验收
真实 Windows 模拟器先保留基线首页、宠物待机、互动、纪念页、惊喜页截图；新增独立技术纹理验证资源、透明混合、分层、热区及释放。这些截图标注为基线或技术测试，不是新版最终美术。

正式素材接入后的五张指定截图需要重新生成并检查字号、触摸范围、缩放、字遮挡、装饰边缘和主题协调；模拟器循环测试检查对象、timer、活动 lease 和像素字节数。固件仅本机 build，报告单列资源增量、最终 app 余量与待板测项。

## 需用户确认
1. 角色选 A/B/C 或指定方向：奶油色小动物、软糯幻想居民、绘本小伙伴。名字待定，不默认套用通用猫头像。
2. 同意“暖窗小房间 + 右侧纪念纸/信封 + 收藏架 Dock”的构图，以及克制的奶油/樱花/薰衣草配色。
3. DSH 第一批素材到达后的具体角色和房间预览；未看到素材不能宣称已完成视觉验收。

后续回忆故事书、拍立得相册、音乐盒和童话游戏中心必须等这两个页面通过视觉验收，再进入重构。
