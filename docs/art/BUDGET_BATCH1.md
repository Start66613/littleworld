## 3. 执行顺序

1. 三张角色概念（同一提示词骨架，只改物种设定，保证风格一致）。
2. 人眼/程序筛选：轮廓、四肢、透明边缘、是否可做动作。
3. 选定角色方向后，用**选中的角色图作为参考图**生成房间（+2 积分），保证配色一致。
4. 房间通过后，再生成首页氛围参考（以角色 + 房间为参考，+4）。
   - 若第 3、4 步带参考图，单价变 12 / 14，合计变为 70 + 2 + 4 = **76**，仍在预算内。
5. 每步产出立刻存 `previews/` 并写 `logs/jobs.jsonl`。

## 4. 不做的事（本批）

- 不做动画（等角色定稿，第二阶段单独立预算）。
- 不做图标/地图/UI 九宫格（A/B/C 三类稳定后再说）。
- 不用 ultimate（20 积分/张，性价比低）。
- 不用 Nano Banana（10/20/40，比 Image2.5 贵且无原生免费抠图）。

## 5. 失败处理

- 任务失败：用 `general-image-poll --job-id <id>` 恢复，**不重复提交**。
- 同一提示词连续 2 次不达标 → 停下来改提示词，不硬刷。
- 每次扣费后立即记录余额，超预算即停。
