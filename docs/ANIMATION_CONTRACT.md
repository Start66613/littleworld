# Little World 动画契约 1.0.0

2026-10-25；Codex 独占维护。遵循 ART_CONTRACT.md 的画布、alpha、4 列行优先和脚底锚点 (128,236)。

## 动作与时间
基础 8 fps（125 ms/帧），允许每帧 duration_ms 在 80–500 ms；播放接口支持 20–2000 ms，技术测试可用更短时间。有限循环首尾接缝须平滑；休息 4 fps。第一批角色定稿前不收费批量生成动画。
- pet.idle：建议 4 帧，循环，轻呼吸/眨眼；避免整个人物上下机械移动。
- pet.happy：建议 2–4 帧，一次，最终回 idle。
- pet.stroke：建议 2–4 帧，一次，闭眼轻靠，不改角色结构。
- pet.eat：建议 3–6 帧，一次，食物不会凭空切换位置。
- pet.play：建议 3–6 帧，一次，躯干和耳尾保持一致。
- pet.sleep：建议 2–4 帧，4 fps 循环，脚底锚点固定；躺姿变化也必须在相同画布内。
- curious/blink 为可选后续动作；当前 mood 缺专属 clip 可映射 idle，明确记录降级。

frame_count ≤32，sequence 只能引用 [0,frame_count)；每帧尺寸/锚点一致。首帧不是封面，所有编号就是实际时间序。交单帧和播放预览，不能用一张合成图替代动画。

## 播放器语义
UI 线程/已持有 BSP LVGL 锁时调用。一个角色最多一个 LVGL timer，每 20 ms 检查截止时间，按真实 elapsed 选择帧；慢帧直接跳到当前时间帧，不突发补画所有漏帧。一次动作结束停在末帧，控制器负责回 idle；循环取总时长模数。uint32 tick 差支持正常 tick 回绕。

play 重置相位；seek 为确定性的毫秒定位；pause 保持当前帧，resume 不补走暂停时间；关闭动画显示首帧且无活动 timer 工作，恢复后重置相位。相同帧不重新加载。资源加载失败保留旧帧，统计失败；无旧帧则隐藏角色并显示缺失提示，由上层决定重试。

新帧获取成功后先换 image src，再 drop 旧 decoder cache/release 旧 lease；预算应容纳当前与下一帧。父页面删除的 LV_EVENT_DELETE 自动停 timer，清空 src 后归还 lease；显式销毁与父级销毁只能走同一条释放路径，不允许双重 free。契约/clip/注册表描述符必须比播放器活得久。

## 场景动作与业务
抚摸/喂食/玩耍/休息热区输出动作事件；现有 lw_pet_interact、lw_pet_mood、lw_app_state_save 继续作为业务来源，资源系统不保存宠物数值。sleep 由 sleeping 状态驱动，不用纯动画改业务。错误/缺资源仍可操作导航。

## 实测要求
Windows 真 LVGL 验证不等帧时长、跳帧、一次/循环、暂停/恢复、禁用动画、失败回退、父级删除、反复进出、多个实例、对象/timer/lease/字节数回落。截图只表示捕获时刻，不替代动画质量评估。最终角色素材还需接触表和锚点/脸部一致性复核；模拟器帧率不能当 ESP32-P4 板测。
